# dsh-workspace-explorer

一个更好的 DSH Web 工作区与会话搜索页面。

## 用途

插件在 DSH Web 侧边栏中新增一个**工作区浏览器**入口。点击图标后打开一个
专用的 `main` 页面，该页面在打开期间会取代会话视图；导航返回会话（例如
通过侧边栏）即可回到会话视图。

查询为空时页面浏览全部内容：

- **工作区** — 按宿主顺序列出所有已注册的工作区
- **会话** — 最近 20 个会话（已归档、空白和子代理会话不显示）

在搜索框中输入内容即可搜索：

- **工作区名称**（标题或目录 basename）— 匹配的工作区出现在“工作区”分组
- **会话标题** — 匹配的会话出现在“会话”分组（标题匹配使用存储的会话标题）
- **会话内容** — 短暂防抖后，来自宿主的全文搜索匹配会合并进“会话”分组；
  “会话”分组上限为 20 条结果，超出时提示缩小搜索范围

仅因工作区名称匹配而命中的会话绝不会出现在“会话”分组中；已归档、空白和
子代理会话在任何位置都不会显示。没有存储标题的会话显示为**未命名**，仍
可通过内容搜索找到。

点击工作区会打开其置顶或最近使用的会话；若该工作区没有可见会话，则在该
工作区中新建会话。点击会话则直接打开该会话。两种情况下，原生工作区侧栏
都会展开该会话所属的工作区分组（工作区树布局中连同祖先分组），并把对应的
会话行（新建会话时为工作区行）滚动到可见位置。

每个工作区行右侧还带有与原生侧栏相同的两个操作按钮，且始终显示：

- **省略号**按钮：以按钮下方为锚点打开原生工作区菜单（重命名、删除以及
  其他已注册的工作区操作）；
- **新建会话**按钮：在该工作区中新建会话，展开原生工作区分组，并返回
  会话视图。

“工作区”分组标题行右侧还带有与原生侧栏相同的“添加工作区”按钮：同款
项目加号图标与 28 px 点击区，来源与原生侧栏加号相同的目录选择流程（复用
当前组合挂载的目录选择后端），选中目录后将其注册为新工作区并像原生操作
一样在新工作区中打开新会话；注册失败时在行内提示。当组合中没有目录选择
流程时，按钮与原生侧栏一样隐藏。

“工作区”分组标题行在“添加工作区”按钮左侧还带有一个**视图选项**按钮，
使用与原生侧栏相同的滑杆图标。点击后打开一个下拉菜单，菜单中只有
**排序方式**一组：

- **手动排序**（默认）— 保持宿主原有顺序；
- **最近更新** — 按每个工作区内最新可见会话的 `updatedAt` 降序排列（最近
  更新的在前；已归档、空白和子代理会话不参与排序）；没有可见会话的工作区
  排在最后，更新时间相同或没有可见会话时回退到宿主顺序。

该选择只影响“工作区”分组（搜索结果中的工作区同样生效），“会话”分组的
顺序保持不变；选择只保存在当前页面内存中，刷新或重新打开页面后回到
“手动排序”。

## 运行要求

- 启用捆绑客户端插件的 DSH Web（客户端模块由浏览器模块加载器加载；
  `dsh.client.inject` 会引入所需的客户端包）。

## 安装

直接从上游 GitHub 仓库安装到当前运行的 DSH Web profile：

```sh
dsh plugin --profile web add github:HeyBlack233/dsh-workspace-explorer
```

pnpm 会从 GitHub 拉取并安装该包，DSH 会把它的捆绑包加入 profile 的图层栈；
`cordis.patch.yml` 负责插入 `dsh-workspace-explorer` 插件行。包本身没有
运行时 npm 依赖，也没有构建步骤，因此无需批准构建脚本。重启 DSH Web
（或等待其 HMR 监听器重载）即可加载新捆绑包。

## 文件结构

- `index.js` — 宿主半边（空操作；所有 UI 由客户端模块负责）
- `client.js` — 浏览器模块加载器模块：侧边栏图标、搜索/浏览页面、纯视图
  派生辅助函数、样式
- `test/client.test.js` — 针对纯辅助函数与模块接线的 Node 测试套件
- `locale/en.json`、`locale/zh.json` — 插件管理器元数据
- `icon.svg` — 侧边栏图标素材
- `cordis.patch.yml` — 图层栈补丁
